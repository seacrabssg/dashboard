## data structure
* Obtain data from regional.json. 
* Data entry without theme will be skipped and not showed on the map
* Please ensure that there are no invalid data entries, especially invalid coordinates, as it will mess up the map.
* If you would like to update the database(regional.json), please convert your csv file to json, remove the top 2 invalid entries, then paste into the regional.json file.
